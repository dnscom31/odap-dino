# 오답 공룡 (odap-dino)

학생의 오답을 모아 AI로 다시 만들어 풀게 하는 **숙제·오답 관리 앱**입니다.
공부할수록 공룡 캐릭터를 키우고 꾸밀 파트를 얻습니다.

- 형태: iOS·안드로이드 앱 (React Native / Expo 예정)
- 과목: 수학, 영어
- 대상: 초등·중등·고등
- 사용자: 선생님, 학부모, 학생
