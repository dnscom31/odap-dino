# 오답 공룡 (odap-dino)

틀린 문제를 찍어 올리고 다시 풀면 공룡이 자라는 **숙제·오답 관리 앱**입니다.
iOS·안드로이드 앱 (React Native + Expo), 서버는 Supabase를 씁니다.

## 지금 되는 것 (1단계: 습관 검증)

| 누구 | 할 수 있는 일 |
| --- | --- |
| 학생 | 가입, 공룡 알 고르기, 숙제 탭에 오답 사진 올리기(하루 10장), "오늘 다 맞았어요", 초대 코드 공유 |
| 학부모 | 초대 코드로 자녀 연결, **만 14세 미만 자녀 동의**, 숙제 내기, 사진 확인·반려 |
| 선생님 | 초대 코드로 학생 연결, 여러 학생에게 한 번에 숙제 내기, 사진 확인·반려 |

**공룡 규칙**

- 사진 1장 +10 XP, 3일 연속마다 +50 XP. 사진 10장이면 알이 부화해요.
- Lv.1 알(0~99) → Lv.2 아기(100~499) → Lv.3 어린이(500~1,199) → Lv.4 성체(1,200~)
- 1단계에서는 Lv.3까지만 진화하고 XP는 계속 쌓여요. 2단계에서 설정만 바꾸면 바로 Lv.4로 진화해요.
- 열린 숙제가 없는 날은 연속 학습이 끊기지 않아요. 숙제 기간 중 빠진 날이 있으면 1일부터 다시.
- 사진이 반려되면 XP는 빠지지만 공룡 레벨은 절대 내려가지 않아요.
- 3일 이상 쉬면 공룡이 잠들어요(벌칙 없음). 숙제를 하면 깨어나요.

점수와 연속 학습은 모두 서버에서 계산하므로 앱에서 조작할 수 없어요.

## 처음 실행하기

### 1. Supabase 준비 (한 번만)

1. [supabase.com](https://supabase.com) 가입 → **New project** (지역은 Seoul 추천)
2. 왼쪽 메뉴 **SQL Editor** → 이 저장소의 `supabase/migrations/0001_stage1.sql` 내용을 전부 붙여 넣고 **Run**
   (모든 표가 `odap` 전용 구역에 만들어져서, 같은 프로젝트의 다른 서비스와 섞이지 않아요)
3. **Project Settings → Data API → Exposed schemas** 에 `odap` 추가 후 Save
4. 베타 테스트 동안 가입을 쉽게 하려면: **Authentication → Sign In / Providers → Email** 에서 *Confirm email* 끄기
   (켜 두면 가입할 때 확인 메일의 링크를 눌러야 해요)
5. **Project Settings → API Keys** 에서 Project URL과 Publishable key(또는 anon key)를 복사

### 2. 앱 실행 (컴퓨터에서)

1. [Node.js](https://nodejs.org) LTS 버전 설치
2. 이 저장소를 내려받은 폴더에서 `.env.example` 파일을 복사해 이름을 `.env` 로 바꾸고, 위에서 복사한 값 두 개를 붙여 넣기
3. 터미널에서 실행

   ```bash
   npm install
   npx expo start
   ```

4. 휴대폰에 **Expo Go** 앱을 설치하고, 화면에 나온 QR 코드를 찍으면 앱이 열려요 (컴퓨터와 폰이 같은 와이파이)

### 3. 써 보기

1. 학생 계정으로 가입 → 홈 화면 아래 **초대 코드** 확인
2. 다른 폰(또는 로그아웃 후)에서 학부모 계정으로 가입 → 초대 코드로 연결 → **동의하기**
3. 학부모 화면에서 **숙제 내기** → 학생 화면에서 사진 올리기

## 운영 설정 바꾸기

Supabase **Table Editor → app_settings** 표에서 숫자만 바꾸면 바로 적용돼요.

| 칸 | 기본값 | 뜻 |
| --- | --- | --- |
| max_level | 3 | 진화할 수 있는 최고 레벨 (2단계에서 4로) |
| daily_upload_limit | 10 | 학생 1명의 하루 업로드 한도 |
| upload_xp | 10 | 사진 1장 XP |
| no_mistake_xp | 0 | "오늘 다 맞았어요" XP |
| streak_bonus_xp / streak_bonus_every | 50 / 3 | 며칠 연속마다 보너스 몇 XP |

```
  login.tsx         로그인·가입
  onboarding.tsx    역할 선택, 공룡 알 고르기
  student/          학생 홈, 숙제 탭(사진 올리기)
  guardian/         학부모·선생님 홈, 숙제 내기, 학생 상세(사진 확인·반려)
src/components/     공룡 그림, 버튼 같은 공용 부품
src/lib/            서버 연결, 날짜·점수 계산
supabase/           데이터베이스 설계 (SQL)
```
