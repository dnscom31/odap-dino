# 오답 공룡 기획서 (요약)

기준일: 2026-10-31

## 1. 개요

오답 공룡은 학생의 오답을 모아 AI로 재생성해 다시 풀게 하는 숙제·오답 관리 앱입니다.
공부할수록 공룡 캐릭터를 키우고 꾸밀 파트를 얻습니다.

- 과목: 수학, 영어
- 대상: 초등·중등·고등으로 나눠 운영
- 쓰는 곳: 학원의 보조 도구, 가정에서 학부모의 보조 도구
- 차별점: 문제 양이 아니라 "오답 다시 풀기"를 게임으로 만드는 것
- 수익 구조: 미정 (학원용·학부모용 요금, 무료 범위)

## 2. 사용자와 역할

| 사용자 | 하는 일 | 받는 것 |
| --- | --- | --- |
| 선생님 | 숙제 탭 생성(날짜·과목·단원), 문제집 PDF 업로드 | 숙제 완료 알림, 반 학생별 오답·약점 리포트 |
| 학부모 | 숙제 탭 생성(날짜·과목·단원) | 숙제 완료 알림, 자녀 오답·약점 리포트 |
| 학생 | 숙제 탭에 오답 사진 업로드, 재생성 문제·시험지 풀기 | 공룡 키우기·꾸미기 파트 |

## 3. 핵심 흐름

1. 선생님·학부모가 숙제 탭 생성
2. 학생이 해당 탭에 오답 사진 업로드
3. 저장 → 단원·유형·난이도 분석 → 기록
4. 문제 재생성
5. 다시 풀기 → 맞히면 공룡 파트 획득, 틀리면 다시 재생성
6. 분석 결과는 리포트·알림으로 선생님·학부모에게 전달

## 4. 문제 재생성 엔진

원문 문제의 표현은 버리고 의도와 접근법만 뽑아 새로 씁니다.

1. 입력: 학생 오답 사진 또는 선생님이 올린 문제집 PDF
2. 의도 추출: 개념, 유형, 핵심 접근법, 난이도 (원문은 분석 후 저장하지 않음)
3. DB 검색: 같은 유형으로 이미 만든 문제 찾기
4. 난이도 조정 재생성: 학생 오답 + DB 문제를 합쳐 학생 수준에 맞게 새로 작성
5. 검증: 계산으로 정답 확인 + 원본과 유사도 검사, 통과 못 하면 폐기
6. 출제 후 정답률 기록 → 난이도 재보정 → DB 저장

운영 원칙

- 도형·그림·그래프는 원본 사진을 잘라서 사용
- 영어는 재생성 품질이 상대적으로 좋아 먼저 적용
- 초기에는 DB에 들어가는 문제를 샘플 검수
- DB가 쌓일수록 AI 호출과 비용이 줄어듦

## 5. 학습 기능

- 숙제 탭: 날짜·과목·단원별
- 재풀이: 원문제 + 재생성 문제, 시간 간격을 두고 다시 출제하는 방식 검토
- 단원 문제·종합 문제: 학생 본인 오답과 재생성 문제로 구성
- 시험지: 단원별·기간별 오답 시험지
- 약점 리포트: 숙제 완료율, 오답률, 약한 단원·유형

## 6. 공룡 보상

- 가입 시 공룡 선택
- 숙제 완료·재풀이 정답으로 성장 포인트와 꾸미기 파트 획득
- 어려운 문제를 맞힐수록 희귀 파트
- 친구와 성장도 비교
- 보상은 "오답 올리기"보다 "다시 풀어서 맞히기"에 더 크게
- 며칠 빠져도 회복이 쉽게

## 7. 기술 구성 (예정)

| 부분 | 쓰는 것 |
| --- | --- |
| 앱 | React Native (Expo), 코드 하나로 iOS·안드로이드 |
| 로그인·저장·알림 | Supabase 또는 Firebase |
| 사진 조판 | Mathpix 같은 수식 인식 서비스 |
| 문제 재생성 | 저가 AI 모델 + 품질이 중요한 곳만 상위 모델 |

## 8. 단계별 개발 계획

1. 1단계 기본 뼈대: 가입·계정 연결, 숙제 탭, 오답 사진 업로드, 알림
2. 2단계 분석과 재풀이: 조판, 단원·유형 분석, 재생성 엔진, 공룡 기본 보상
3. 3단계 리포트와 시험지: 약점 리포트, 단원·종합 문제, 시험지, PDF 업로드
4. 4단계 확장과 출시: 공룡 꾸미기 확장, 친구 경쟁, 결제, 스토어 출시

## 9. 위험 요소

| 사용 습관 | 1단계에서 실제 학생으로 먼저 검증 |
